# JUGNO FIGHTER 3D

A mobile-friendly browser fighting-game prototype built with HTML, CSS, JavaScript and Three.js.

## Play
After GitHub Pages is enabled and the deployment workflow completes, open:

https://syedm515151-sketch.github.io/Jugno-Fighter-3D/

## Features
- 10 selectable fighter color/name presets
- 3D arena and simple 3D fighter models
- CPU opponent with basic chasing and attack behavior
- Touch controls for phones
- Keyboard controls for desktop browsers

## Controls
- Phone: left/right buttons to move, up button to jump-position, Punch and Kick to attack.
- Keyboard: arrow keys or WASD to move, J to punch, K to kick.

## Run locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr, so the first load requires internet access.

## Current status
This is an early playable prototype, not a finished commercial game. Fighter models and animations are placeholders made from 3D shapes. APK packaging, richer animations, sound, and full testing on Android are still future work.
