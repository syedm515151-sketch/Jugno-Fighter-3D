# ARSLAN MODEL 786

A mobile-friendly 3D fighting-game prototype built with HTML, CSS, JavaScript and Three.js.

## Play
After GitHub Pages is enabled and the deployment workflow completes, open:

https://syedm515151-sketch.github.io/Jugno-Fighter-3D/

## Current prototype features
- 10 selectable fighter presets, including ARSLAN
- 3D arena with a CPU opponent
- Basic punch, kick, special-power and movement controls
- Touch controls for phones and keyboard controls for desktop browsers

## Controls
- Phone: use the on-screen movement, Punch, Kick and Special Power buttons.
- Keyboard: arrow keys or WASD to move, J to punch, K to kick, and L for special power.

## Run locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr.

## Development status
This is an early playable prototype, not a finished commercial game. The current fighter bodies are simple placeholder 3D shapes, not realistic human-quality character models. Realistic character assets, detailed animations, sound, Android APK packaging and device testing are still required.
